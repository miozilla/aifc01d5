# aifc01d5 🔑🌎💼
aifc01d5 : AWS KMS Amazon Macie # AIF-C01 # Encryption # PII # AI Security Tool # KMS # Bucket Policy # S3


## Objective
- To encrypt data in an Amazon S3 bucket by using an AWS KMS key.
- To create an S3 bucket policy to enforce encryption on uploaded objects.
- To use Amazon Macie to identify PII stored in objects in the S3 bucket.
